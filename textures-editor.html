Drawing into whole sprite

Right-click paints transparent. Use Draw then / Draw else on an if op to edit that branch's appearance; Draw inside edits an each body. Branch patches stay inside their op. repeat is edited through its nested ops.

Values are JSON: a number, "#rrggbbaa", a list, or an expression such as ["+", ["param","x"], 1]. Fields named as, texture, file and fn are plain strings.
